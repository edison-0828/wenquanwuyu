# 松间温泉

一款日式像素风温泉度假村经营游戏。玩家从山间小旅馆起步，沿着石板路布置客房、露天温泉和庭园，再把生意拓展到木桥对岸的温泉街。

## 本地试玩

游戏源码在根目录的 `index.html`。页面包含游戏画面、样式和逻辑，使用 HTML、CSS、JavaScript 和 Canvas，无需安装前端依赖。

下载仓库后，在仓库目录运行以下命令。需要 Python 3。

```bash
python -m http.server 5191
```

然后在浏览器打开 [本地试玩页面](http://127.0.0.1:5191/)。

## 怎么玩

1. **建造和升级**。点地图空地选设施，点已有设施查看详情。客房、温泉、商店和庭园设施可升至 6 级。
2. **接通道路**。石板路、鹅卵石路和木栈道可以混铺。经营设施需要接通旅馆入口，游客才能到访。
3. **布置庭园**。摆放樱花树、锦鲤池、牌坊等装饰，也能养鸟和鱼。环境评分越高，来客越多，遇见稀客的机会也越大。
4. **开始营业**。每天营业约 30 秒。游客会入住、泡汤和逛店，收摊后可在账簿查看收入和维护费。旅行团预约会在部分营业日前弹出。
5. **扩展地图**。点「土地出售」木牌购买新区。接通木桥后，游客可以走到对岸的温泉街消费。

拖动地图可以移动镜头，点「全景」或「近景」切换视角。手机和桌面浏览器均可操作。

## 存档

游戏会自动保存到当前浏览器的本地存储。营业中刷新或重新打开页面时，可以继续当天的进度。请使用同一浏览器和同一站点地址续玩。清除该站点数据会删除存档。

当前版本为 **v0.71**。
